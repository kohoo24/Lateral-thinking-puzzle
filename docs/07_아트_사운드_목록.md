# 아트·사운드 목록 (6단계)

데모에 필요한 에셋 목록이다. 우선순위는 "필수"(데모에 반드시 필요)와 "선택"(있으면 좋음)으로 나눈다.

## 공간과 이동 방식

공간은 등대 안 다섯 곳이다. 제작 범위를 작게 유지하기 위해 자유 이동 3D가 아니라, 공간마다 고정된 1인칭 시점 몇 장면을 클릭으로 오가는 방식을 제안한다.

| 공간 | 주요 시점 | 들어 있는 것 | 우선순위 |
| --- | --- | --- | --- |
| 등실(꼭대기) | 바다를 향한 창 전경, 신호등 앞 | 신호등과 레버, 본등, 등유통과 게이지, 대답 규칙 카드, 360도 창 | 필수 |
| 당직실(2층) | 책상, 벽면 | 근무 일지, 액자(뒤에 신문 조각), 벽시계, 창문 | 필수 |
| 나선 계단 | 계단 위에서 내려다본 시점, 13번째 칸 앞 | 13번째 칸 표시, 아래 창고 문 | 필수 |
| 창고(계단 아래) | 좁은 내부 한 장면 | 서약서 상자, 크레인의 편지 봉투 | 필수 |
| 입구(1층) | 문 쪽, 선반 쪽 | 방명록 선반, 바깥 문(수칙 6 이벤트) | 필수 |
| 배 갑판(배드 엔딩) | 갑판에서 등대를 바라본 한 장면 | 부서진 난간, 멀리 등대 | 필수 |

**시점 원칙:** 게임의 중심은 등실이다. 플레이어는 대부분의 시간을 신호등 앞에서 보내고, 단서를 볼 때만 다른 공간으로 간다. 공간 사이 이동은 계단을 오르내리는 짧은 발소리와 암전으로 처리한다.

## 소품

상호작용하는 소품은 확대해서 읽을 수 있어야 하며, 상태 변화가 있는 소품은 그 상태별 그림이 필요하다.

| 소품 | 상호작용 | 필요한 상태 | 우선순위 |
| --- | --- | --- | --- |
| 근무 일지 | 펼치기, 넘기기, 확대 | 수칙 페이지, 수칙 2 확대(긁힌 종이와 갈색 잉크 흔적), 뒷장 메모, 오염 단계별 번진 글씨가 늘어난 페이지, 최종 제출 페이지, "answer"로 채워지는 페이지(인정 0개 배드 엔딩), 플레이어 메모 페이지(숨겨진 엔딩) | 필수 |
| 신문 조각 | 액자 뒤에서 꺼내기, 펼치기, 확대 | 접힌 상태, 펼친 상태(본 기사·작은 기사·여백 메모) | 필수 |
| 방명록 | 펼치기, 이름 입력 | 시작 시 빈 줄, 진 엔딩·부분 엔딩(번진 정도 2종)·배드 엔딩 상태 | 필수 |
| 크레인의 편지 | 봉투 열기, 읽기 | 한 번 뜯겼다 다시 접힌 봉투, 펼친 편지 | 필수 |
| 역대 서약서 5장 | 넘겨보기 | 이름 선명(2장), 이름 번짐(2장), 번지는 중(헤일) | 필수 |
| 빈 서약서 | 서약 입력 | 빈 양식, 서약 후 | 필수 |
| 신호등과 레버 | 레버 당기기, 길게 눌러 억지로 당기기 | 덮개 열림·닫힘, 폭풍으로 잠김, 등유 마지막 칸에서 잠김, 신호가 바람에 흩어짐 | 필수 |
| 본등 | 보기만 함 | 불꽃 크기 3단계(평상, 등유 부족, 꺼짐), 오염 단계별 색온도 | 필수 |
| 등유통과 게이지 | 보기만 함 | 25칸 게이지(마지막 칸 빨간색), 출렁임, 다시 차오름(신호가 닿지 않음) | 필수 |
| 대답 규칙 카드 | 확대 | 한 장 | 필수 |
| 벽시계 | 보기만 함 | 게임 속 시각 표시 | 선택 |
| 액자 | 뒤집기 | 앞면 사진(등대 흑백 사진), 뒷면 | 선택 |

**단서 비교 보기:** 일지, 신문 조각, 방명록, 서약서 중 두 개를 골라 화면에 나란히 펼쳐 놓는 기능이 필요하다. 필체 비교가 핵심 2의 열쇠라서 필수다.

## 필체 세트

필체는 핵심 2의 유일한 열쇠라 가장 공들여야 할 에셋이다. 같은 사람의 필체는 어디서 나오든 확실히 같아 보여야 한다. 단서 속 필체는 영어 원문 이미지를 쓰고 한국어 버전은 자막을 붙인다.

| 필체 | 나오는 곳 | 우선순위 |
| --- | --- | --- |
| 오웬(갈색 만년필) | 수칙 1·3·4·5, 뒷장 메모, 수칙 2 아래 긁힌 흔적, 방명록, 서약서 | 필수 |
| 브룩스(연필) | 수칙 6, 방명록, 서약서 | 필수 |
| 헤일, 마른 파란 볼펜(y·g 꼬리) | 신문 여백 메모, 방명록, 서약서 | 필수 |
| 헤일, 번진 파란 볼펜 | 수칙 2, 오염으로 일지에 늘어나는 "answer", 인정 0개 배드 엔딩 | 필수 |
| 크레인 | 고백 편지, 서약서, 방명록 | 필수 |
| 태너 | 방명록, 서약서 | 필수 |
| 플레이어 | 방명록 이름, 엔딩 날짜, 숨겨진 엔딩 메모. **한글도 지원해야 한다** | 필수 |

## 바다·불빛·날씨

배는 거의 보여주지 않고 불빛으로만 존재한다. 등실 창밖 풍경이 게임 화면의 대부분을 차지하므로 이 부분의 완성도가 분위기를 결정한다.

| 요소 | 필요한 상태 | 우선순위 |
| --- | --- | --- |
| 배의 불빛 | 첫 신호(불규칙한 짧은 모스), 대답 4종(예·아니오·상관없음·다시 보내라), 거짓 대답의 푸르스름한 빛깔, 잔광, 세 번 깜빡임과 그 뒤 희미하게 남는 빛 | 필수 |
| 수면 반사 | 4단계 메아리. 배 아래 물 위에서 천천히 번졌다 사라지는 빛 | 필수 |
| 배의 거리 | 오염 단계에 따라 3단계(멀리, 조금 가까이, 바로 앞바다) | 필수 |
| 배의 실루엣 | 번개가 칠 때 한 번 드러나는 부서진 여객선 | 필수 |
| 날씨 | 5단계(약한 바람, 비, 강풍, 번개와 높은 파도, 폭풍 최고조) | 필수 |
| 창 | 김 서림, 손바닥 자국, 빗줄기 | 필수 |
| 하늘 | 밤, 제출 단계에서 점점 밝아지는 수평선, 잿빛 새벽(진 엔딩·부분 엔딩) | 필수 |
| 화면 효과 | 오염 단계별 가장자리 어두워짐, 물 번짐, 채도 감소 | 필수 |
| 수평선의 희미한 불빛 | 진 엔딩 마지막 장면 | 선택 |

**불빛 원칙:** 배의 불빛은 늘 같은 흰빛 등불을 기본으로 하고, 거짓 대답의 푸른 기운은 처음 보는 사람은 모를 정도로 약하게 한다. 색 차이는 게임 안의 여러 모니터 환경에서 테스트해야 한다.

## UI 요소

화면 위에 떠 있는 UI는 최소화하고, 가능한 것은 게임 속 물건(등유 게이지, 대답 규칙 카드, 교신 기록)으로 보여준다.

| UI | 설명 | 필요한 상태 | 우선순위 |
| --- | --- | --- | --- |
| 질문 입력창 | 신호등 앞에 놓인 종이 쪽지 형태 | 오염 5단계별 모습, 글자 수 표시(1단계부터), 끼어든 단어의 번진 잉크 표시, 지워지는 글자 효과 | 필수 |
| 교신 기록 | 보낸 질문과 받은 대답을 한 줄씩 적은 기록지 | 일반, 초반 질문이 바뀐 상태(2→3 전환) | 필수 |
| 모스 해독 표시 | 배가 먼저 보내는 신호(이름)를 한 글자씩 보여줌 | 1회용 | 필수 |
| 단서 비교 보기 | 문서 두 장을 나란히 펼치는 화면 | 확대, 이동 | 필수 |
| 최종 제출 페이지 | 일지 마지막 장 형태의 입력 화면 | 스스로 제출, 강제 제출(창밖이 새벽빛으로 밝아짐) | 필수 |
| 배드 엔딩 버튼 | 한 번 깜빡이기, 두 번 깜빡이기 | 1종 | 필수 |
| 결과 화면 | 엔딩 뒤 한 장짜리 요약 | 엔딩 4종 | 필수 |
| 이름 입력 | 게임 시작 때 방명록에 쓰는 화면 | 1종 | 필수 |
| 타이틀·설정 | 언어(영어·한국어), 소리, 색각 보조 | 기본 | 필수 |
| 일시정지 화면 | 게임 화면을 완전히 가림. ESC, 창 전환, 네트워크 끊김 때 표시 | 일반, 재연결 대기 | 필수 |

**접근성:** 거짓 대답의 색 차이를 보기 어려운 플레이어를 위해 설정에 "색각 보조"를 두면, 거짓 대답에 들리는 낮은 울림 소리의 기본 크기가 커진다. 울림은 색과 똑같이 오염이 깊어질수록 약해지다가 3단계부터 사라진다.

## 사운드

조용한 공포는 소리가 대부분을 만든다. 음악은 거의 쓰지 않고, 환경음의 작은 변화로 긴장을 쌓는다.

| 구분 | 소리 | 쓰이는 곳 | 우선순위 |
| --- | --- | --- | --- |
| 환경음 | 파도(잔잔함~탑에 부딪힘 4단계) | 전체 | 필수 |
| 환경음 | 바람(약함~폭풍 4단계), 비(가랑비·굵은 비) | 폭풍 진행 | 필수 |
| 환경음 | 본등 불꽃 타는 소리, 벽시계 초침 | 등실, 당직실 | 필수 |
| 환경음 | 물속처럼 먹먹한 필터 | 오염 4단계, 배드 엔딩 | 필수 |
| 효과음 | 신호등 레버, 덮개 여닫힘 | 신호 보내기 | 필수 |
| 효과음 | 등유 꿀렁임 | 등유 1 감소 | 필수 |
| 효과음 | 레버가 잠겨 버티는 삐걱임 | 등유 마지막 칸 | 필수 |
| 효과음 | 바람에 신호가 흩어지는 소리, 거꾸로 나는 꿀렁임 | 신호가 닿지 않음(등유 되돌림) | 필수 |
| 효과음 | 종이 넘기기, 펜 쓰기 | 일지, 방명록, 서약서 | 필수 |
| 효과음 | 계단 삐걱임, 발소리 | 공간 이동 | 필수 |
| 효과음 | 창고 문 열림 | 수칙 5 | 필수 |
| 효과음 | 유리창 떨림, 천둥(낮은·긴 2종) | 폭풍 | 필수 |
| 효과음 | 탑 전체가 한 번 울리는 소리 | 35분 마지막 경고 | 필수 |
| 효과음 | 바위에 배가 닿는 소리 | 마지막 등유를 신호로 쓴 배드 엔딩 | 필수 |
| 효과음 | 거짓 대답의 낮은 울림 | 거짓 대답 | 필수 |
| 효과음 | 노크, 계단을 올라오는 젖은 발소리 | 수칙 6 | 필수 |
| 효과음 | 초침 한 박자 늦음·멈춤 | 오염 1·3단계 | 선택 |
| 음성 | 헤일의 목소리(대사 4줄) | 수칙 6 | 필수 |
| 음성 | 파도에 섞인 웅얼거림, 플레이어 이름 속삭임 | 오염 2단계, 수칙 4 위반 | 필수 |
| 음악 | 낮게 깔리는 드론 1곡 | 타이틀, 결과 화면 | 필수 |
| 음악 | 새벽 테마 짧은 1곡 | 진 엔딩 | 선택 |

**음성 녹음 결정 필요:** 헤일의 대사는 영어로만 녹음하고 한국어는 자막으로 처리하는 방안을 제안한다. 대사가 4줄뿐이고, 1980년대 영어권 등대라는 배경에도 맞는다. 플레이어 이름 속삭임은 이름이 사람마다 달라 녹음할 수 없으므로, 알아들을 수 없는 속삭임에 이름 자막을 겹치는 방식으로 처리한다.
