# 별도 검증 세트 (보류 세트)

검증 질문 세트(docs/03)를 보며 사실 목록과 판정 원칙을 고쳐 왔기 때문에, 그 세트의 점수는 실제 플레이어 질문에서의 품질보다 높게 나올 수 있다. 이 세트는 **판정 규칙을 고칠 때 보지 않은 질문**으로 실제 품질을 따로 확인하기 위한 것이다.

## 이 세트를 쓰는 규칙

- **규칙을 고치는 데 쓰지 않는다.** 어긋난 항목을 보고 프롬프트나 판정 원칙을 고치면, 그 항목은 더 이상 보류 세트가 아니다. 고쳐야 할 문제가 보이면 그 문제를 docs/03에 **다른 문장으로** 옮겨 적고, 거기서 고친다.
- 고치는 데 쓴 항목은 이 세트에서 빼고, 같은 종류의 새 문장으로 바꿔 넣는다. 바꾼 항목은 아래 수정 이력에 적는다.
- 실행 시점: 큰 규칙 수정을 마쳤을 때와 출시 전. 결과는 docs/03 합격 기준과 같은 기준으로 본다.
- 문장은 docs/03의 질문, 진상 문서(docs/02) 판정 원칙의 예시, 프롬프트(judge/src/prompt.ts, jev-judge.ts)의 예시와 겹치지 않게 쓴다. `npm test`가 겹침을 검사한다.
- 형식은 docs/03과 같다. `npm run extract`가 `content/holdout-tests.json`으로 옮기고, `npm run judge:test -- --set holdout`으로 실행한다.
