# 게임 클라이언트 (M1: 등실 한 장면)

TypeScript + Vite + PixiJS. 장면과 빛은 PixiJS로, 입력창·교신 기록·등유 게이지는 HTML로 그립니다. 아트가 들어오기 전이라 장면은 그레이디언트와 빛 효과만으로 그렸습니다.

## 실행

```bash
cd judge && npm install && cd ../app && npm install
npm run dev:mock      # 개발용 가짜 판정 서버 + 게임 (http://localhost:5173)
```

- 실제 판정으로 해보려면 `judge`에서 `npm run serve`(판정 AI 키 필요)를 따로 띄우고 `app`에서 `npm run dev`를 실행합니다.
- 주소 뒤에 `?debug`를 붙이면 오염 점수·단계·마지막 판정이 보이고, **F8**로 오염 점수를 8씩 올려 단계 전환을 바로 볼 수 있습니다.
- 가짜 판정은 검증 질문 세트에 있는 문장(예: "2번 수칙은 가짜야?", "너 매년 돌아와?")에는 기대 결과대로, 나머지는 임의로 대답합니다.

## M1에 들어간 것

| 기능 | 문서 |
| --- | --- |
| 질문 입력 → 모스 신호(2~3초) → 기다림(최소 1.5초, 2단계부터 길어짐) → 배의 불빛 대답 4종 | docs/05 |
| 거짓 대답의 푸르스름한 빛(단계가 오를수록 흐려짐) | docs/05 |
| "신호가 닿지 않음": 우리 신호등 불꽃이 흔들리고 등유를 돌려줌 | docs/05 |
| 등유 25칸, 마지막 빨간 칸에서 레버 잠김, 길게 눌러 억지로 당기면 등불이 꺼짐 | docs/01, 05 |
| 오염 점수와 단계(판정 서버가 계산한 점수 + 끼어든 배의 이름 +5) | docs/01 |
| 0→1 전환: 등불이 크게 흔들림, 창에 김, 글자 수 표시 | docs/05 |
| 1→2 전환: 배가 묻지 않았는데 플레이어의 이름을 모스로 보냄, 배가 가까워지고 등불이 차가워짐 | docs/05 |
| 2단계 끼어드는 단어(세 번에 한 번, 파란 잉크, 한글 조합이 끝난 뒤 0.5초) | docs/05 |
| 단계별 입력 분량(100% / 75% / 50%) | docs/01 |
| 게임 시작 때 배의 첫 신호(불규칙한 짧은 모스) | docs/05 |

아직 없는 것: 폭풍 시계와 일시정지, 세 번 깜빡임 이벤트, 3단계 이상의 지워지는 단어, 다른 공간과 단서, 소리, 제출과 엔딩(배드 엔딩은 자리만 있음).
