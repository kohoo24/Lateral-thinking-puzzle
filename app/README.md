# 게임 클라이언트 (M2: 전체 흐름)

TypeScript + Vite + PixiJS. 등실 장면과 빛·날씨는 PixiJS로, 입력창·교신 기록·문서·다른 공간은 HTML로 그립니다. 아트가 들어오기 전이라 등실은 그레이디언트와 빛 효과로, 다른 네 공간은 임시 화면(소품 버튼)으로 그렸습니다.

## 실행

```bash
cd judge && npm install && cd ../app && npm install
npm run dev:mock      # 개발용 가짜 판정 서버 + 게임 (http://localhost:5173)
```

- 실제 판정으로 해보려면 `judge`에서 `npm run serve`(판정 AI 키 필요)를 따로 띄우고 `app`에서 `npm run dev`를 실행합니다.
- **웹 플레이 빌드:** `npm run build:web`은 판정 서버 없이 claude.ai 아티팩트에서 열 수 있는 빌드를 `dist-web/`에 만듭니다(상대 경로). 판정은 `src/judge-claude.ts`가 아티팩트의 `sample` 기능으로 보는 사람의 Claude 계정에 묻습니다. 규칙 문장(`judge/src/prompt.ts`)과 불빛·오염 규칙(`judge/src/light.ts`)은 판정 서버와 같고, 판정 AI만 Jev 대신 Claude라 결과가 조금 다를 수 있습니다. 질문 판정은 빠른 모델, 최종 제출은 기본 모델로 묻습니다. 첫 질문에서 Claude 사용 허용을 묻고, 허용하지 않으면 모든 질문이 "신호가 닿지 않음"이 됩니다.
- 주소 뒤에 `?debug`를 붙이면 경과 시간·오염 점수·단계·마지막 판정이 보입니다. **F8**은 오염 +8, **F9**는 폭풍 시계 +5분입니다.
- `?speed=20`처럼 붙이면 폭풍 시계가 그 배로 빨리 갑니다(40분 → 2분).
- ESC로 일시정지합니다. 창을 전환하거나 최소화해도 자동으로 멈춥니다.
- 가짜 판정은 검증 질문 세트에 있는 문장(예: "2번 수칙은 가짜야?", "너 매년 돌아와?")에는 기대 결과대로, 나머지는 임의로 대답합니다.

## 들어간 것

**M1(등실)**: 질문 → 모스 신호 → 기다림 → 불빛 대답 4종, 거짓 대답의 푸른빛, 신호가 닿지 않음(등유 반환), 등유 25칸과 마지막 칸 잠금, 오염 점수와 단계 전환, 끼어드는 단어, 배의 첫 신호.

**M2(전체 흐름)**

| 기능 | 문서 |
| --- | --- |
| 공간 다섯 곳: 등실, 당직실, 나선 계단, 창고, 입구. 신호는 등실에서만 | docs/07 |
| 단서 문서: 수칙(필체·날짜·긁힌 자국, 오염 시 번진 글씨와 "answer"), 뒷장 메모, 신문 조각, 방명록, 크레인의 편지, 역대 서약서. 한국어는 번역 자막 | docs/04 |
| 문서 두 장 나란히 보기(필체 비교) | docs/07 |
| 폭풍 시계 40분: 날씨 5단계, 30분 이후 번개(첫 번개에 배의 실루엣 한 번), 35분 마지막 경고, 37분 폭풍 도착·강제 제출, 40분 해가 뜨며 판정 | docs/05 |
| 수칙 3: 세 번 깜빡임(8분, 이후 6분마다, 창고를 연 뒤 3분마다), 15초 안에 신호를 보내면 +5 | docs/05 |
| 수칙 5: 창고 문(등유 2, 마지막 칸 아래로는 안 내려감), 편지·서약서 | docs/01, 02 |
| 수칙 6: 25분 또는 3단계에 문밖의 헤일(대사 자막), 문을 열면 +8 | docs/05 |
| 서약서: 1~2단계에서 1회, 판정 서버로 판정, 한 단계 회복 | docs/01 |
| 오염 3·4단계: 자신을 가리키는 말이 1초 뒤 지워짐, 초반 질문이 "Should I come aboard?"로 바뀜, 입력창 서리 | docs/05 |
| 최종 제출: 스스로 또는 37분 강제, 제출 중에도 단서 열람, 판정 서버로 핵심 개수 판정 | docs/06 |
| 엔딩 4종: 진 엔딩, 숨겨진 엔딩(신호 0회), 부분 엔딩(이름 번짐 2종), 배드 엔딩(역할 반전: 1년 뒤 새 등대지기의 질문에 버튼으로 대답) | docs/06 |
| 결과 화면(어긴 수칙은 표시하지 않음) | docs/06 |
| 일시정지(ESC, 창 전환, 창 최소화) | docs/01 |

아직 없는 것: 실제 아트와 소리, 네트워크가 끊겼을 때의 자동 일시정지, 스팀 빌드(M3·M4).
